# Antidetect profiles: fingerprint and proxies

## Profile kinds

| Kind | Protection level | Behaviour |
| --- | --- | --- |
| **antidetect** (default) | `normal` | Own realistic fingerprint + own network identity. **Nothing is blocked**: no ad/tracker blocking, cookies and popups work normally, so every site behaves as in plain Chrome. |
| personal, work, testing, custom | `standard` | Ad/tracker blocking and privacy defaults. |
| private, temporary | `strict` | Strict blocking; temporary profiles are deleted when closed. |
| tor | `tor` | Tor network, fixed settings. |

The level can be changed per profile in the browser's privacy panel
(`Normalny / Standard / Ścisły`).

Popups: in `normal` and `standard` profiles, `window.open` creates a real
popup window with a working `window.opener`, which OAuth logins and payment
flows need. A popup is only allowed within 1.5 s of a user click or keypress.
This stops pop-under spam but does not break legitimate logins.

## Fingerprint (`profile.fingerprint`)

Generated by `generateFingerprint({ os })` in `packages/core/src/fingerprint.ts`.
All values stay consistent with each other and with the real engine:

* **User agent / UA-CH**: the Chrome major version always equals the real
  Chromium engine version. Sites cannot detect a mismatch between the claimed
  version and the supported JS/CSS features. The `Sec-CH-UA*` headers,
  `navigator.userAgentData` (including `getHighEntropyValues`) and
  `navigator.platform` all match the chosen OS.
* **OS**: Windows 11, Windows 10, macOS, Linux. Changing the OS regenerates
  the UA, GPU, screen and CPU values but keeps the network settings.
* **WebGL**: `noise` (default) adds deterministic noise to `readPixels`.
  `webglInfo` can be `real` or `manual` (vendor + renderer). Presets per OS
  cover common real GPUs, e.g. ANGLE Direct3D11 NVIDIA/AMD/Intel on Windows and
  Apple M1-M3 on macOS.
* **Canvas, AudioContext, ClientRects, fonts**: `noise` gives a stable per-profile
  noise, derived from `seed`. The same profile gives the same hash on every
  visit; different profiles give different hashes.
* **WebRTC**:
  * `altered` (default): WebRTC works, but only the proxy's public IP is exposed.
  * `disable-udp`
  * `manual`: a custom public IP.
  * `real`
  * `off`
* **Timezone / language / geolocation**: `auto` means "based on the proxy
  IP". The proxy check fills in the timezone, the `Accept-Language` list and
  the coordinates. Each can also be set manually or, for geolocation, blocked.
* **CPU cores, device memory, screen, media devices, Do-Not-Track, port-scan
  protection**: set to realistic values, or manual.

`fingerprintWarnings()` reports inconsistent manual edits, for example a macOS
UA with a Direct3D GPU, a UA version different from the engine, or an
unrealistic core count on a Mac. The editor shows these as warnings before
you save.

### How it is applied

* **Page and iframes**: a preload shim (`preload/page-shim.ts`) runs in the main
  world before any page script. The patched getters look native:
  `toString()` returns `[native code]`, and there are no extra own properties.
* **Workers and headers**: the CDP overrides in `main/fingerprint-runtime.ts`
  (`Emulation.setUserAgentOverride` with UA metadata, timezone, locale,
  geolocation) apply to service and dedicated workers. Request headers are
  rewritten in `session-privacy.ts`.

Known limitation: `about:blank` iframes created and scripted synchronously
may run before the preload in some Electron versions.

## Proxies

Supported types: HTTP, HTTPS, SOCKS4, SOCKS5 (SOCKS5 with a login goes
through a local authenticated bridge, because Chromium cannot authenticate
SOCKS itself).

### Automatic format detection

Paste any of these. The type comes from the scheme if present, otherwise from
the selected type:

```
host:port
host:port:user:pass
user:pass@host:port
user:pass:host:port
host:port@user:pass
socks5://user:pass@host:port        (http, https, socks4, socks5, socks5h, socks)
[2001:db8::1]:1080
host:port:user:pass [https://change-ip-url]
```

The launcher parses the input while you type. It shows the detected type,
address and format; if the line is invalid, it says why. Mass add (**Proxy →
Dodaj proxy**) accepts one proxy per line and lists the result for each line.

### Check

**Sprawdź** connects through the proxy and shows the exit IP, country, city,
timezone and latency. For `auto` fingerprints, that timezone, language and
location are used, so they match the IP.

### Storage

Host, port and type are stored in `profiles.json`. Usernames and passwords are
stored only in the encrypted secret store (`proxy:<profileId>` / saved-proxy
ids). They are never included in Chromium proxy rules, logs or API responses.
