# Zgłaszanie podatności / Security policy

**PL** – Jeśli znajdziesz podatność w OctoBrowser.su lub OctoDetect.su, **nie publikuj jej w publicznym zgłoszeniu**. Użyj prywatnego zgłoszenia GitHub: zakładka *Security → Report a vulnerability* w repozytorium `chargehuobey/lvocto`. Opisz wersję, system, kroki odtworzenia i wpływ. Nie dołączaj swoich haseł, kluczy ani prywatnych danych profilu.

**EN** – Please report vulnerabilities privately via GitHub *Security → Report a vulnerability* in `chargehuobey/lvocto`. Include version, OS, reproduction steps and impact. Do not include passwords, keys or private profile data.

Wspierana jest tylko najnowsza wersja. Poprawki bezpieczeństwa są wydawane z wagą **security** i instalowane przez wbudowany updater (manifest podpisany Ed25519).

Zakres: kod w tym repozytorium. Podatności w Chromium/Electronie zgłaszaj odpowiednio do projektów Chromium i Electron; OctoSuite przejmuje ich poprawki przez aktualizację Electrona.
